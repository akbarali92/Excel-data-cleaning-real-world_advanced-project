## 🚀 Project Overview

This project demonstrates a complete real-world data cleaning process using Microsoft Excel. The dataset provided was highly messy and contained multiple inconsistencies such as missing values, incorrect data types, inconsistent formatting, and invalid entries.

The goal of this project was to transform raw, unstructured data into a clean, structured, and analysis-ready dataset.

---

## 🎯 Objectives

- Clean and preprocess messy sales data
- Standardize inconsistent formats
- Handle missing and invalid values
- Prepare dataset for analysis and dashboarding

---

## 🛠️ Tools Used

- Microsoft Excel

---

## 🔥 Key Data Cleaning Steps

### ✅ 1. Handling Missing Values
- Replaced missing values using logical assumptions and defaults
- Used functions like `IF` and `IFERROR`

### ✅ 2. Date Standardization
- Converted multiple date formats into a single format (DD-MM-YYYY)
- Used `DATEVALUE`, `SUBSTITUTE`, and formatting techniques

### ✅ 3. Text Cleaning
- Removed extra spaces using `TRIM`
- Standardized text using `UPPER` / `PROPER`
- Fixed inconsistent naming (e.g., Lahore, lahore, LHR → Lahore)

### ✅ 4. Data Type Conversion
- Converted text to numeric using `VALUE`
- Cleaned symbols like `$` and `%`

### ✅ 5. Discount Cleaning
- Standardized discount values (10%, 0.1 → 0.10)
- Handled invalid entries (`N/A`, `??`) using `IFERROR`

### ✅ 6. Logical Error Handling
- Identified and handled negative quantities
- Corrected invalid inputs (e.g., "two" → 2)

### ✅ 7. Revenue Calculation
- Created calculated column using:
  
  Revenue = Quantity × Price × (1 − Discount)
